# Living Knowledge — Daily

> Folder ini berisi konteks harian yang dapat diperbarui setiap hari.

## Cara Menggunakan

Buat file Markdown di folder ini dengan nama format: `YYYY-MM-DD-topik.md`

Contoh: `2026-07-26-news.md`

## Template

```markdown
# Daily Update — [Tanggal]

## Ringkasan Hari Ini
[Isi dengan ringkasan peristiwa atau topik hari ini]

## Konteks Tambahan
[Informasi tambahan yang relevan]
```

## Catatan

File di folder ini akan dimuat secara otomatis oleh backend Haven jika sesuai konteks percakapan.
