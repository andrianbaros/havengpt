# Living Knowledge — Monthly

> Folder ini berisi konteks bulanan untuk review dan ringkasan topik besar.

## Cara Menggunakan

Buat file Markdown di folder ini dengan nama format: `YYYY-MM-topik.md`

Contoh: `2026-07-recap.md`

## Template

```markdown
# Monthly Recap — [Bulan Tahun]

## Topik Terbesar Bulan Ini
[Isi dengan ringkasan peristiwa besar]

## Perkembangan Penting
[Perkembangan yang paling signifikan]

## Outlook Bulan Depan
[Prediksi atau hal yang perlu diperhatikan ke depan]
```

## Catatan

File di folder ini ideal untuk ringkasan panjang yang membutuhkan konteks lebih luas.
